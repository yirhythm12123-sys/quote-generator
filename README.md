# quote-generator

社内向け 見積書自動作成ツール（ブラウザだけで動く静的Webアプリ）

## 使い方

`index.html` をブラウザで開くだけで使えます。サーバー不要。社内配布する場合は `index.html` / `app.js` / `style.css` の3ファイルをそのまま渡してください。

CDN（Vue 3 / ExcelJS / FileSaver.js）を読み込むため、初回起動時はインターネット接続が必要です。

## 機能

- 共通情報（見積番号・発行日・有効期限・顧客情報・自社情報・備考）を入力
- 1見積に対し**複数の案**（案A / 案B / …）を並行作成可能。タブで切替
- 明細行ごとに以下を入力：
  - 品目名 / 数量 / 単位 / 出値単価 / 出元（部・SE）/ 費用区分（初期・月額・都度）/ 利益モード
- 利益モードは出元×費用区分の組合せにより選択肢が動的に変化：

  | 出元 | 費用区分 | 選択可能な利益モード |
  |------|----------|--------------------|
  | 部   | 初期 / 月額 / 都度 | `営業のみ (/0.9)` または `そのまま` |
  | SE   | 初期 / 都度 | `部+営業 (/0.8/0.9)` 固定 |
  | SE   | 月額 | `部+営業 (/0.8/0.9)` / `部のみ (/0.8)` / `そのまま` の3択 |

- 顧客提示単価・金額をリアルタイムで自動計算（単価レベルで四捨五入）
- 案ごとに**内部用サマリ**（顧客出値・企画依頼金額・営業利益・SE出値・粗利・粗利率）を表示
- **Excel出力**: 1案=1シート。費用区分は存在するものだけ表示する柔軟レイアウト。担当・上長の印枠付き。シート末尾に内部用サマリ（※社外秘）を出力

## 計算式

| 利益モード | 顧客提示単価 |
|-----------|-------------|
| `部+営業 (both)` | `Math.round(出値 / 0.8 / 0.9)` |
| `営業のみ (sales)` | `Math.round(出値 / 0.9)` |
| `部のみ (dept)` | `Math.round(出値 / 0.8)` |
| `そのまま (none)` | `出値` |

| サマリ項目 | 計算 |
|-----------|------|
| 顧客出値 | 顧客提示単価 × 数量 |
| 企画依頼金額 | `sales` / `both` のとき 顧客出値 × 0.9（営業利益除く）、`none` / `dept` は顧客出値 |
| 営業利益 | 顧客出値 − 企画依頼金額 |
| SE出値 | 出元=SE のとき 出値 × 数量、それ以外は 0 |
| 粗利 | 企画依頼金額 − SE出値 |
| 粗利率 | 粗利 ÷ 顧客出値 × 100 |
