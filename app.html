見積書自動作成ツール

📖 使い方ガイド (クリックで開閉)
🎯 4ステップで担当営業向け見積Excelを生成
① 基本情報→ ② 明細入力→ ③ 案の管理→ ④ Excel出力

1 基本情報を入力

共通情報
  • 案件名(任意) / 発行日(本日が初期値) / 有効期限
顧客情報
  • 会社名のみ入力。株式会社が前後に付いていてもExcel出力時に自動で除去
担当営業情報
  • 会社名: 一覧から選択 ⇄ 自由記入 をタブで切替
  • 担当営業（姓）: 姓のみを入力(例: 山田) → Excel上は「担当営業 山田様」と表示

2 明細を入力

2-1. 費用区分を選ぶ
  • 各行の先頭セルから 初期 / 月額基本 / 月額従量 / 都度 を選択
  • 選んだ瞬間に単位・備考の既定値が入る
2-2. 品目プリセットで一括入力
  • 品目名のプルダウンから選ぶと 単価・単位・備考・利益モードを自動セット
  • セット セット品目(POS接続方式 / デジタルギフト / 決済アプリ連携 等)はどれか1つ選ぶだけで関連する区分の行も自動追加
プリセット選択は何度でもやり直せます。区分を変えるとプリセット候補も自動で切替わる。
2-3. 出元と利益モード
  • 出元 = 部 / SE を選択
  • 利益モードは出元×費用区分で選択肢が動的に変化:
    • 部+営業 = 出値÷0.8÷0.9 (両者乗せ)
    • 営業のみ = 出値÷0.9
    • 部のみ = 出値÷0.8 (SE月額のみ)
    • そのまま = 利益乗せなし
2-4. 出値単価と顧客出値
  • 出値単価はカンマ不要。フォーカスを外すと自動でカンマ整形
  • 顧客出値は端数があれば千円単位で自動切上げ
  • 右の調整プルダウンで +1,000〜+9,000 加算 → 「元に戻す」でリセット
2-5. 月額従量料金の率調整
  • 「月の従量料金」プリセットは ±1.5% を 0.1%刻みで調整可能
  • 例: 月の入金金額に対して 1.5% が基準の場合、
    -0.5% を選択すると「月の入金金額に対して 1.0%」と
    出値単価・自動計算額・顧客出値に反映
2-6. 行を追加・削除・並べ替え
  • 表下の「行を追加」で新規行、行末の「削除」で削除
  • 行頭の ⋮⋮ ハンドルをドラッグすると行の並べ替えが可能(タッチ対応)
2-7. 備考欄の自動サイズ
  • 横幅: 全行の中で最長行に合わせて自動拡張(全行統一)
  • 縦幅: 各行ごとに改行数に合わせて自動フィット
  • 等幅フォントで表示され、Excel出力時もそのままレイアウトを維持

3 案を管理

複数案の並行作成
  • 「案を追加」で 案A / 案B… と並行管理 (Excelでは 1案 = 1シート)
  • 「案名変更」で固有名を付与可能 (例: 標準プラン)
タブのドラッグで並べ替え
  • タブ左の ⠿ をドラッグして順番入替 → Excel のシート順にもそのまま反映
  • 削除すると 案A/B/… は自動繰り上げ。固有名はそのまま保持
案をリセット
  • 案が1つの場合だけ表示。明細のみ初期化し、共通情報・顧客・担当営業はそのまま保持

4 サマリ確認 → Excel出力

4-1. 内部用サマリで利益確認
  • 各案の下に展開される内部用サマリパネルで以下を一覧:
  • 顧客出値 / 企画依頼金額 / 営業利益 / SE出値 / 粗利
  • 区分ごとの小計と案合計、最下部に粗利率(%)も表示
4-2. Excel出力
  • 「Excel出力」ボタンで自動生成・ダウンロード
  • ファイル名: 【会社名様】担当営業向け御見積書(案件名)_YYYYMMDD.xlsx
  • レイアウト: 横向きA4 / 1ページ自動スケール / TOPPAN自社情報・担当上長印枠を自動配置
  • 備考は等幅フォント(ＭＳ ゴシック)で全文が見える行高・列幅で出力
  • 各案の末尾に内部用サマリセクションを付与 (※社外秘)

⚠️ 内部用サマリ(社外秘)はExcelの各シート末尾に含まれます。
顧客に送付する前に該当セクションを必ず削除してください。
